Privacy Policy

Effective Date: January 1, 2026

1. Information Collection

RavenEye collects minimal information necessary for functionality:

  • API Key: Your OCR.space API key is stored locally in your browser using encrypted chrome.storage.sync. It never leaves your device.
  • Settings: User preferences (auto-copy, image quality) are stored locally in your browser.
  • Screen Captures: Temporary screenshots are captured for OCR processing and immediately deleted after processing completes.

2. Data Sharing

RavenEye shares data only with services necessary for core functionality:

  • OCR.space API: Screen captures are sent to OCR.space for text extraction. Images are processed and immediately deleted by OCR.space. Review their privacy policy at ocr.space/privacypolicy
  • No Third-Party Analytics: We do not use Google Analytics, tracking pixels, or any third-party analytics services.

3. Data Storage

  • All data is stored locally in your browser using Chrome's secure storage APIs
  • No data is stored on our servers (we don't have any servers)
  • Data syncs across your browsers if you're signed into Chrome sync

4. Permissions Explanation

RavenEye requires the following permissions:

  • activeTab: Required to capture visible tab content for OCR processing
  • tabs: Required to access current tab for screen capture functionality
  • scripting: Required to inject content script for overlay UI during selection
  • storage: Required to save user settings and API key securely in browser
  • clipboardWrite: Required to copy extracted text to clipboard when requested
  • downloads: Required to save extracted text as .txt files when requested
  • host_permissions: Required to capture screen content from any website you visit

5. Open Source

RavenEye is fully open source. You can review the entire codebase, verify our privacy claims, and contribute at GitHub.

6. Changes to Privacy Policy

Any changes to this privacy policy will be posted on this page. Continued use of the extension after changes indicates acceptance of the updated policy.

7. Contact

For privacy concerns or questions, contact us through the Support section.

Quick Troubleshooting

Extension not activating?

Check if keyboard shortcut conflicts exist in edge://extensions/shortcuts. Try reassigning the shortcut if needed.

API key not saving?

Click the Save button after entering your key. Wait 1-2 seconds before closing the popup. Verify the key is masked (showing dots) after save.

OCR results are empty?

Ensure you're selecting a region with actual text. Increase zoom level for better capture quality. Check if your API key is valid at OCR.space dashboard.

Invalid API key error?

Verify you copied the entire key from your email. Check if you've exceeded the 25,000 monthly request limit. Register for a new free key if needed.
