Planning
Understand what you're building before writing a line of code
🧠 Core Architecture Decisions Design
DecisionChoiceReason
Manifest versionMV3Chrome requires MV3 for new extensions (MV2 deprecated)
OCR engineTesseract.js v5Runs 100% in browser, no API keys, no server cost
Screenshot APIcaptureVisibleTabBuilt into Chrome Extensions — captures the whole tab
Storagechrome.storage.syncSettings sync across devices automatically
UI stackVanilla JS/CSSNo build tools needed for v1, fast to ship
💡 Key insight: The extension captures a full screenshot, then crops it to your selection rectangle in a Canvas element. The cropped image is then sent to Tesseract.js for OCR — all locally.
🔄 User Flow Design
User presses Ctrl+Shift+E (or clicks icon)
Background script fires → sends message to content script
Screen dims + crosshair cursor
Overlay injected into page with configurable dim intensity
User drags selection rectangle
mousedown → mousemove → mouseup tracked on the overlay
Overlay removed → screenshot taken
80ms delay so the overlay doesn't appear in the capture
Region cropped via Canvas API
Full screenshot is cropped to exact selection rect × devicePixelRatio
OCR runs in browser via Tesseract.js
Tesseract loaded from CDN, processes the cropped image locally
Result popup appears with extracted text
User can copy text, save image, or dismiss

Local Development Setup
Get the extension running in your browser
📥 Get the Code Terminal

Download the project files from GitHub once you've pushed them (Step 3), or work from the folder directly:

# Clone after pushing to GitHub
git clone https://github.com/YOUR_USERNAME/raveneye.git
cd raveneye
✓ All the extension files are already built and ready in the extension/ folder — no build step required for v1.
🧩 Load in Chrome (Developer Mode) Browser
  • Open Chrome and navigate to chrome://extensions/
  • Toggle "Developer mode" ON (top-right corner)
  • Click "Load unpacked"
  • Navigate to and select the extension/ folder
  • 🦅 RavenEye icon appears in your toolbar!
⚠️ If you modify any files, click the ↻ reload button on the extension card at chrome://extensions/ to see changes.
🧪 Testing Checklist Test
  • Press Ctrl+Shift+E on any page — screen should dim
  • Drag a selection over text — rectangle appears
  • Release — result popup appears with "Extracting text..."
  • OCR completes — text appears in popup
  • "Copy Text" copies to clipboard
  • ESC key cancels the selection
  • Popup icon → settings → change dim slider → test again
⚠️ OCR Note: Tesseract.js loads from CDN on first use (~3MB). This takes a few seconds initially but is cached after that. Best results on dark-on-light text, size 12pt+.
03
GitHub — Version Control & Releases
Push your code and set up automated releases
🐙 Create the GitHub Repository GitHub.com
  • Go to ↗ github.com/new
  • Repository name: raveneye
  • Description: "🦅 Browser extension that extracts text from screen selections using OCR"
  • Set to Public (required for Chrome Web Store review transparency)
  • Do NOT initialize with README (you already have one)
  • Click Create repository
📤 Push Your Code Terminal 
# Inside your RavenEye project folder
git init
git add .
git commit -m "🦅 Initial commit — RavenEye v1.0.0"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/raveneye.git
git push -u origin main
🏷️ Create a Release (Auto-packages ZIP) Terminal

The .github/workflows/release.yml GitHub Actions workflow automatically creates a packaged .zip of your extension whenever you push a version tag:

# Tag v1.0.0 → triggers GitHub Actions → creates release with .zip
git tag v1.0.0
git push origin v1.0.0

Go to your repo → Actions tab to watch it run. Then Releases → you'll see raveneye-v1.0.0.zip ready to download.

✓ This ZIP is exactly what you upload to the Chrome Web Store. It packages only the extension/ folder contents.

Chrome Web Store — Publishing
Get RavenEye live for everyone to install
💳 Developer Registration (One-Time) One-Time
  • Go to ↗ Chrome Developer Dashboard
  • Sign in with a Google account
  • Pay the one-time $5 USD developer registration fee
  • Wait for account verification (usually instant)
💡 The $5 fee is a one-time payment per Google account. After that, publishing unlimited extensions is free.

📝 Store Listing Content Required

Name: RavenEye — Screen Text Extractor

Short Description (132 chars max):

Select any region on screen and instantly extract the text inside. Powered by local OCR — no data ever leaves your browser.

Detailed Description:

🦅 RavenEye — See everything. Capture anything.

RavenEye lets you draw a selection rectangle on any part of your
screen and extracts all text from that region instantly, using
OCR that runs entirely inside your browser.

HOW IT WORKS:
→ Press Ctrl+Shift+E (or click the icon)
→ Screen dims — ready to select
→ Drag a rectangle over any text
→ Text is extracted and copied to clipboard

FEATURES:
✓ Local OCR (Tesseract.js) — no API, no server, no cost
✓ Works on images, PDFs, videos, websites — anything visible
✓ Configurable dim & blur intensity
✓ Optional: save captured region as PNG
✓ 7 accent color themes
✓ Keyboard shortcut support
✓ 100% private — zero data leaves your device

PERFECT FOR:
• Copying text from images you can't select
• Extracting text from YouTube subtitles
• Capturing text from PDFs with broken copy
• Grabbing text from screenshots
• Reading text from any visual element

Category: Productivity

Language: English

🚀 Upload & Submit for Review Dashboard
  • In the Developer Dashboard, click "New item"
  • Upload raveneye-v1.0.0.zip (from your GitHub Release)
  • Fill in name, description, and store listing content (see above)
  • Upload all required screenshots and the store tile
  • Set visibility to Public
  • Under "Permissions justification" — explain why you need activeTab and scripting (for OCR), downloads (to save images)
  • Click Submit for Review
⏳ Review time: Usually 1–5 business days for first submission. Updates to existing extensions are reviewed faster (often within hours). You'll get an email when approved or if changes are needed.
